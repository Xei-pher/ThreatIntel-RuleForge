# Security Policy

## Reporting a vulnerability

Do not disclose security vulnerabilities in a public issue.

Use GitHub's **Security → Report a vulnerability** flow (private vulnerability reporting) for this repository. Include affected versions, reproduction steps, impact, and any suggested remediation.

If private vulnerability reporting is temporarily unavailable, contact the repository maintainer through their GitHub profile without publishing exploit details.

## Scope notes

ThreatIntel RuleForge processes untrusted PDF uploads and may send report-derived data to optional third-party APIs when configured. Security reports involving file handling, path traversal, secret exposure, unsafe generated output, dependency compromise, or unintended third-party data disclosure are especially relevant.

No bounty program is currently offered.
